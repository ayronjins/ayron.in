Privacy / Plain language

Privacy notice.

Effective 13 September 2026. This notice covers the limited information ayron.in actually handles.

First-party analytics

This portfolio doesn't run advertising trackers, account registration or profiling cookies. What it does use is a first-party Umami setup for basic page views, referrers and performance events, served directly through ayron.in with no third-party advertising scripts involved.

Standard server logs

Like most websites, the server may briefly log technical request data: IP address, timestamp, requested path, browser identifier, response status. That's for reliability, abuse prevention and security troubleshooting, not advertising.

Email

If you email me, your address and message pass through the email providers involved and are kept only as long as needed to respond. Please don't send passwords or other secrets.

Tools Lab diagnostics

Submitting a public domain or page URL to Domain Observatory or Site Intelligence sends it to the server for processing. Those requests get validated against public DNS destinations and are capped in both time and size; none of it is kept as scan history. Network Architect is different. Its calculations stay in the browser and never reach the server.

External services

pc.ayron.in and news.ayron.in are run as part of Ayron Jins's other technical projects. Any link that takes you off this domain is covered by that destination's own privacy terms, not this one.

Contact and corrections

Got a privacy question or spotted something inaccurate? Email Ayronjins4@gmail.com.
